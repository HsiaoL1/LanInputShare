# Mac / Mac 双机验收

当前状态：**尚未进行真实 Mac 双机验收**。自动测试和单机打包烟测不能替代两台设备上的输入操作。

记录两端应用版本、系统版本、CPU 架构、显示器分辨率与缩放、物理网卡 IPv4 和主控方向。

- [ ] 两端授予辅助功能；主控另授予输入监控。退出并重新启动应用后权限检查通过。
- [ ] 客户端先监听，主控填写客户端局域网 IPv4；首次连接在客户端核对设备名和证书指纹并确认。
- [ ] 鼠标跨相邻边缘进入远端，并可从远端边缘或 Control+Option+Esc 返回；本机光标位置恢复。
- [ ] 左键、右键、中键、拖拽、双击和触控板纵向及横向滚动正常。
- [ ] 字母、数字、中文输入法、功能键、方向键，以及 Command、Control、Option、Shift 的左右键正常。
- [ ] Command+C/V/A/Z 在远端按 Mac 快捷键生效；Control+Option+1/2/3 切换设备正常。
- [ ] 按住键或鼠标键时断网、暂停、退出，远端没有卡键，本机输入恢复。
- [ ] 两端文字、截图和文件复制粘贴正常，剪贴板没有循环同步。
- [ ] Secure Input 和锁屏场景按已知限制处理，不会让本机输入持续被拦截。
